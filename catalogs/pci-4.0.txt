# PCI DSS v4.0 -- catalog of requirements.
#
# Source 1 (most lines): official document "Payment Card Industry Data
# Security Standard -- Summary of Changes from PCI DSS Version 3.2.1 to
# 4.0, Revision 1" (PCI Security Standards Council, May 2022), downloaded
# from
# https://listings.pcisecuritystandards.org/documents/PCI-DSS-v3-2-1-to-v4-0-Summary-of-Changes-r1.pdf
# The section 5 table ("Additional Changes per Requirement") was parsed
# and the number from the "PCI DSS v4.0" column was taken ONLY when it
# was unambiguously identified: either an explicit old->new mapping in
# the same table row, or a row marked textually "New requirement." Rows
# with a single number and no such marker were discarded on purpose,
# because in several cases that number is the OLD (v3.2.1) ID of a
# requirement the table marks "Removed" -- including it would have put
# a requirement that doesn't exist in v4.0 into the catalog.
#
# Source 2 (a handful of lines): "Related requirements: PCI DSS
# v4.0.1/X.Y.Z" citations that appear on AWS Security Hub control pages
# (RDS, S3, Lambda, Redshift, CloudTrail, SecretsManager, WAF, SSM)
# fetched in this session.
#
# WHAT'S MISSING: PCI DSS v4.0 has more than 300 numbered requirements
# (12 main requirements + appendices A1-A3 for service providers /
# specific entities). This catalog has 125, almost all "core"
# requirements that changed or are new relative to v3.2.1 -- the source
# document is a diff of changes, not the full standard, so requirements
# that did NOT change between versions and weren't cited by Security Hub
# simply aren't here (example: most of the "a/b/c" sub-clauses of
# testing procedures, and almost all of Appendix A). To complete: the
# full standard is at
# https://docs-prv.pcisecuritystandards.org/PCI%20DSS/Standard/PCI-DSS-v4_0.pdf
# (requires accepting PCI SSC's terms to download).
# complete: no  (125 of ~300 requirements, see the note above)
#
